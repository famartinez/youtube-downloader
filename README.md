# YouTube MP3 Downloader

A simple Python command-line tool that downloads audio from a YouTube video and converts it into an MP3 file using `yt-dlp` and `ffmpeg`.

## What This Project Does

This program allows you to paste a YouTube video link into the terminal and download the audio as an MP3 file.

It also prints basic video information before downloading, including:

- Video title
- View count

The downloaded MP3 file is saved to the user’s Windows Downloads folder.

## Technologies Used

- Python
- yt-dlp
- ffmpeg
- Windows PowerShell
- Git / GitHub

## Requirements

Before running this project, make sure you have:

- Python installed
- yt-dlp installed
- ffmpeg installed
- Git installed
